    Please open it through a web server

    This page cannot be started by double-clicking it: for file:// the browser blocks both modules and data requests from other origins. Everything works through a small web server.

    cd ~/lichess-puzzle-finder
    node build/serve.mjs 8123

    Then open in the browser:

    http://127.0.0.1:8123/

    With --host 0.0.0.0 it is also reachable from your phone on the same network.
