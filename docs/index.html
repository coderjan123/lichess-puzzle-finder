    Bitte über den Server öffnen

    Diese Seite lässt sich nicht per Doppelklick starten: der Browser verbietet bei file:// Module und Datenzugriffe aus fremden Herkünften. Über einen kleinen Webserver läuft alles.

    cd ~/lichess-puzzle-finder
    node build/serve.mjs 8123

    Dann im Browser öffnen:

    http://127.0.0.1:8123/

    Mit --host 0.0.0.0 zusätzlich unter der LAN-Adresse erreichbar.
